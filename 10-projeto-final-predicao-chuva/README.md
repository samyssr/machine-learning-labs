# 10 - Projeto Final: Modelo de Predição de Chuva (Rainfall Prediction)

Este projeto prático representa a etapa de conclusão e avaliação final do curso **Machine Learning with Python** da IBM. O objetivo principal é construir, avaliar e comparar múltiplos modelos de aprendizado supervisionado para prever se choverá ou não no dia seguinte com base em dados meteorológicos históricos.

---

## 🎯 Objetivos do Projeto

* Realizar Análise Exploratória de Dados (EDA) e limpeza de dados meteorológicos.
* Tratar variáveis categóricas via *One-Hot Encoding* e normalizar atributos numéricos.
* Treinar e avaliar diferentes algoritmos de classificação:
  * Regressão Logística
  * K-Nearest Neighbors (KNN)
  * Árvores de Decisão (Decision Trees)
  * Support Vector Machines (SVM)
* Comparar o desempenho dos modelos utilizando métricas como **Acurácia**, **Jaccard Index**, **F1-Score**, **Log Loss** e **MA/MSE/R2**.

---

## 🛠️ Tecnologias e Bibliotecas

* **Python 3**
* **Scikit-Learn:** Implementação dos classificadores, pré-processamento e métricas de avaliação.
* **Pandas & NumPy:** Manipulação e tratamento de datasets tabulares.
* **Matplotlib & Seaborn:** Visualização de matrizes de confusão e distribuição de dados.

# 🚀 Machine Learning & Data Science Labs

Bem-vindo(a) ao meu repositório central de estudos e projetos práticos em **Ciência de Dados** e **Aprendizado de Máquina**. 

Aqui organizo meus laboratórios, códigos em Python e documentações focadas em transformar dados brutas em análises e modelos preditivos com explicabilidade (*Explainable AI*).

## 🛠️ Tecnologias e Ferramentas
* **Linguagem:** Python 3
* **Análise & Manipulação de Dados:** Pandas, NumPy
* **Machine Learning & Estatística:** Scikit-Learn
* **Visualização de Dados:** Matplotlib, Seaborn
* **Ambiente de Desenvolvimento:** Google Colab, Jupyter Notebooks


## 📂 Estrutura do Repositório & Projetos

Os projetos estão divididos por áreas de estudo. Clique em qualquer pasta para acessar o notebook e a documentação detalhada de cada laboratório:

### 📊 01. Regressão
* **`01-regressao-emissao-co2/`**: Predição de emissão de CO2 veicular com base no tamanho do motor utilizando Regressão Linear Simples e Múltipla.

### 🎯 02. Classificação
* **`02-classificacao-churn/`**: Modelo de Regressão Logística para predição de rotatividade de clientes (*churn*) em telecomunicações.
* **`02-classificacao-obesidade/`**: Classificação multiclasse para identificação de níveis de risco de obesidade.
* **`02-classificacao-medicamentos/`**: Recomendação automatizada de medicamentos utilizando Árvores de Decisão, com análise de **Entropia** e **Ganho de Informação**

## 📌 Principais Aprendizados Desenvolvidos
1. **Engenharia de Features e Pré-processamento:** Tratamento de dados ausentes, categorização e padronização.
2. **Avaliação de Modelos:** Aplicação de métricas como Matriz de Confusão, Acurácia, Log Loss e análise de curvas.
3. **Explicabilidade:** Extração de regras claras de decisão a partir de modelos baseados em árvore para interpretação de negócios.

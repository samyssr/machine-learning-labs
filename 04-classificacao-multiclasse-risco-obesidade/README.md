Classificação Multiclasse - Risco de Obesidade
Projeto em Python para prever níveis de risco de obesidade utilizando Regressão Logística com as estratégias One-vs-All (OvA) e One-vs-One (OvO).

📌 O que foi feito
Pré-processamento: One-Hot Encoding para texto, Label Encoding para o alvo e padronização com StandardScaler.

Análise: Visualização gráfica da importância de cada variável no modelo.

Automação: Criação de uma função de Pipeline (obesity_risk_pipeline) que carrega os dados, treina e avalia o modelo em uma única linha.
